# Kalkulator Kurs USD-IDR

Kalkulator konversi dua arah Dolar AS ke Rupiah dan sebaliknya.

- Kurs awal: Rp18.027 per USD (penutupan 16 Oktober 2026, sumber iNews.id)
- Kurs bisa diganti langsung di kolom "Pakai kurs lain"
- Buka `index.html` di browser, atau aktifkan GitHub Pages (Settings > Pages > Branch: main)
